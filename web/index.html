About This System
This Raspberry Pi provides the web interface for the CNC system.

The Raspberry Pi communicates with the BTT SKR Pico, which runs grblHAL and controls the CNC machine.

CNCjs provides the machine-control interface.
Files provides access to stored G-code and other CNC files.
Terminal provides a web-based DietPi terminal running under the dietpi account.
